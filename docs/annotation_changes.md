# 标注修订记录

**规则**（用户，2026-09-26）：有明确证据证明原标注不合理、而我们的解析更合理时，修改标注。
用户补充（2026-09-26，阶段五）：标注本身也是由文档解析工具生成的；标注偏离最合适的结果、质量不如我们的解析时，采用我们的，可以灵活处理。

- 只改错误或自相矛盾之处。两种写法都说得通的（风格选择）不改，例如：
  - 单位写成 LaTeX 还是 Unicode；
  - 合并单元格在每行重复写；
  - 网页界面文字排除与否。
- 每条修改记下文档、改动与证据。
- `ground_truth/` 中大多数文件只在本地（不入 git），`ground_truth_public/` 由公开数据集转换而来。修改前的版本不另存，以本表为准。

此前的修订（text_pic02、patent01 的"附图说明"标题等）记在 [redesign_guide.md](redesign_guide.md) §15（2026-09-25）。
